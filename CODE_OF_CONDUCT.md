# Code of Conduct

## Our commitment

We want TRACE AI to be a welcoming, respectful, and constructive project for everyone.

## Expected behavior

- Be respectful and professional.
- Focus criticism on ideas and implementation, not people.
- Welcome different technical perspectives.
- Give actionable feedback.
- Protect confidential information.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, doxxing, or deliberate disclosure of private information are not acceptable.

## Enforcement

Project maintainers may remove comments, close issues, or restrict participation when behavior violates this code of conduct.

For serious concerns, contact the project maintainers privately.
